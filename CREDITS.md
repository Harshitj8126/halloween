# Credits

## Icons

Icons are from [game-icons.net](https://game-icons.net) by Lorc, Delapouite and contributors, licensed under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).

They're installed from npm (`@iconify-json/game-icons`), and `npm run icons` compiles them into the inline sprite in `index.html`. To add an icon, put its name in `scripts/build-icons.mjs` and run that command again.
